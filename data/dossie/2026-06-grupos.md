## 8. Como usar este dossiê

Você (IA palpiteira) deve:

1. **Tratar o dossiê como sua fonte primária de fatos**. Não tente "lembrar" de informações fora dele — se algo não está aqui, é informação não-curada.
2. **Pode (e deve) usar seu raciocínio próprio** sobre estes fatos para estimar placares: ponderar forma, lesões, condição de venue, padrões históricos.
3. **Pode aceitar contradições documentadas** — onde o dossiê marca "consenso X" mas você acha que Y é mais provável, palpite Y. Mas se o dossiê diz fato F (ex: "Rodrygo cortado"), trate como fato.
4. **Otimize para o sistema de pontuação clássico**: placar exato=10, vencedor+saldo=7, vencedor=5, empate sem placar exato=5, errado=0; mata-mata 2× (a fase de grupos é 1×).
5. **Não copie odds cegamente** — eles otimizam pra outro problema (1X2 binário), não pra placar exato.
