Como funciona

O passo a passo de como as IAs palpitam, como medimos confiança e como o ranking é montado.

  1. 01

    Coleta dos jogos oficiais

    Importamos da FIFA os 104 jogos da Copa 2026 (72 da fase de grupos + 32 do mata-mata), com times, datas, horários e venues. Fonte cruzada com Sky Sports, ESPN e NBC. Todos os horários no fuso de Brasília.

    🗓️
  2. 02

    Dossiê de contexto padronizado

    Para que todas as IAs recebam exatamente as mesmas informações, montamos um dossiê único com:

    • Análise dos 12 grupos com probabilidades Opta
    • Odds agregadas de mercados de futebol
    • Lesões e cortes confirmados (Rodrygo, Estêvão, Messi etc.)
    • Condições de venue (altitude Cidade do México, calor Dallas, etc.)
    • Padrões históricos de placar em Copas
    • Notas táticas relevantes

    Dossiê gerado pelo Claude Opus 4.7 via WebSearch cruzando 7 fontes em 03–05/06/2026.

    📚
  3. 03

    Duas vias de coleta paralelas

    🌐 Via web manual Série A

    10 IAs top, uma por empresa, coletadas na interface web oficial com search nativo (ChatGPT 5 Pro, Claude Opus 4.7, Gemini 2.5 Pro, Grok 4 Heavy, etc.). Cada IA pesquisa internet do jeito que sabe.

    ⚡ Via API OpenRouter

    57 IAs (de Phi-4 mini a Llama 4 Maverick) coletadas via API com o mesmo dossiê padronizado. Permite comparação justa entre modelos sem viés de search.

    🔀
  4. 04

    Regras de pontuação clássicas

    AcertoPontos
    Placar exato10
    Vencedor + saldo de gols7
    Apenas vencedor5
    Empate sem placar exato5
    Errado0

    Mata-mata vale 2×. Vale o tempo regulamentar (90 min). Prorrogação e pênaltis são ignorados para fins de placar do palpite.

    📏
  5. 05

    Bola de cristal & medidor de confiança

    Para cada jogo, calculamos:

    • 🔮 Bola de cristal: placar mais votado entre todas as IAs (modal estatístico).
    • Confiança: % das IAs que concordam no placar modal. Verde (≥50% forte), amarelo (30–49% médio), rosa (<30% fraco).

    Quando >50% das IAs concordam, é sinal de jogo "no papel". Quando <30%, é jogo aberto com muita dispersão de palpites.

    🔮
  6. 06

    Ranking dinâmico

    O ranking é recalculado a cada jogo apurado. Ordenação:

    1. Pontos totais (decrescente)
    2. Placares exatos (desempate 1)
    3. Vencedores acertados (desempate 2)
    4. Popularidade da IA (desempate 3 — Statcounter web traffic)
    5. Ordem alfabética do slug (último recurso)
    🏆
  7. 07

    Pós-Copa: análise comparativa

    No fim do torneio, comparamos:

    • Qual empresa teve melhor desempenho médio (OpenAI vs Anthropic vs Google etc.)
    • Qual família de modelo se destacou (reasoners vs não-reasoners)
    • Qual via ganhou: web (com search) vs API (com dossiê)
    • Quem chutou mais ousado (palpites únicos) vs quem seguiu o consenso
    📊
