# F4.5 — Coletor API (OpenRouter) + Dossiê padrão

**Sprint**: 05–08/06/2026 (3 dias)
**Arquiteto**: esta sessão
**Decisão de produto** (registrada em `docs/DECISOES.md`):
- Coletar palpites via 2 vias: (a) **WEB manual** pra Tier 1 (16 IAs top, search nativo); (b) **API OpenRouter** pra todas as 105 (incluindo as Tier 1 pra ter dupla coleta).
- IAs API recebem **dossiê padrão** anexado ao prompt — neutraliza a desvantagem de não ter web search e garante comparação justa entre modelos. Dossiê é gerado pelo Arquiteto (Claude Opus 4.7) com web search habilitada.
- Slugs API: tal como estão hoje (ex: `chatgpt-5`).
- Slugs WEB extras: sufixo `-web` (ex: `chatgpt-5-web`) — apenas Tier 1.

## Objetivo da feature

Habilitar coleta automatizada de palpites das 105 IAs via OpenRouter, com dossiê padronizado, mantendo a opção de coleta manual via web pras top tier.

## Divisão por agente

### 🛠 pipeline-dev — `src/bolao/coletor.py` + CLI `coletar`

**Entregáveis**:

1. `src/bolao/coletor.py`:
   - `coletar_via_openrouter(slug: str, modelo: str, prompt: str, dossie: str) -> str`
     - Chama API OpenRouter (`https://openrouter.ai/api/v1/chat/completions`).
     - Auth: lê `OPENROUTER_API_KEY` do env. Se ausente → `RuntimeError` com mensagem clara.
     - Monta `messages = [{"role": "user", "content": f"{prompt}\n\n## DOSSIÊ DE REFERÊNCIA\n\n{dossie}"}]`.
     - Retorna o conteúdo da resposta.
     - **Timeout**: 120s. **Retry**: 3x com backoff exponencial (1s, 3s, 9s).
   - `coletar_lote(ias: list[dict], prompt: str, dossie: str, max_paralelo: int = 5) -> list[dict]`:
     - Itera `ias` em paralelo (asyncio + httpx), com `Semaphore(max_paralelo)`.
     - Para cada IA bem-sucedida, salva resposta em `data/palpites_ias/<slug>.md` (com header `<!-- modo: api -->`, `<!-- modelo: <openrouter_id> -->`, `<!-- coletado_em: <ISO> -->`).
     - Retorna lista `[{"slug":..., "ok":bool, "erro":str|None}]`.
   - **Não derruba** se uma IA falhar — pula e continua.

2. `config/openrouter_mapping.json`:
   - Mapping `slug → openrouter_model_id`. Cobertura inicial:
     - Tier 1: `chatgpt-5` → `openai/gpt-5`, `claude-opus-4-7` → `anthropic/claude-opus-4-7`, `gemini-2-5-pro` → `google/gemini-2.5-pro`, `grok-4` → `x-ai/grok-4`, `deepseek-r1` → `deepseek/deepseek-r1`, `qwen-3-max` → `qwen/qwen3-max`, etc.
     - Tier 2: os mid/light dos mesmos provedores.
     - Tier 3-8: open source via meta-llama, mistralai, microsoft, etc.
   - Use a [lista de modelos do OpenRouter](https://openrouter.ai/models) como referência. IAs sem cobertura ficam fora do JSON (vão precisar de web).

3. `src/bolao/__main__.py` — novo subcomando:
   - `python -m bolao coletar [--tier N|all] [--ia <slug>[,<slug>]] [--dry-run]`
   - `--dry-run`: imprime quais IAs seria, sem chamar API.
   - `--ia chatgpt-5`: força só essa.
   - `--tier 1`: só Tier 1. `--tier all`: tudo que tem mapping.
   - Lê dossiê de `data/dossie/<rodada-atual>.md` (parametrizável via `--dossie <path>`; default = última rodada conhecida).

4. Adicionar dep `httpx>=0.27` em `pyproject.toml`.

**Não cuide de**: testes (qa-tester depois), prompt (llm-prompt), docs (docs-writer).

**Reporte em**: `reports/F4.5-coletor-api/pipeline-dev.md`.
